# 📄 AI Resume Analyzer

An AI-powered resume analysis platform that evaluates resumes for ATS readiness, extracts skills, identifies improvement areas, and compares resumes against job descriptions.

## 🚀 Features

- Upload resumes in PDF, DOCX, or TXT format
- Automatic resume text extraction
- Resume text preprocessing
- Technical skill extraction
- Soft skill extraction
- ATS-style resume analysis
- Resume scoring from 0–100
- Resume section completeness analysis
- Keyword analysis
- Action verb analysis
- Measurable achievement detection
- Contact information detection
- Resume-to-job matching
- Keyword overlap analysis
- Skill matching
- Resume/job text similarity
- Professional Streamlit dashboard
- Automated parser tests
